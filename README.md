## Windows Setup Instructions

1. Install Git for Windows.
2. Open Git Bash.
3. Sign in to your GitHub account.
4. Accept the repository collaborator invitation.
5. Clone the repository using:

    git clone https://github.com/Princess655/cit240-team-project.git

6. Open the project folder:

    cd cit240-team-project

7. Check the repository:

    git status

## How to View the Page

1. Open the project folder.
2. Find index.html.
3. Double-click index.html to open it in a browser.
